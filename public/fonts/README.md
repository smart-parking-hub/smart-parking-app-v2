# Local typefaces

Be Vietnam Pro (400, 500, 600, 700, 800) and Source Sans 3 (variable 400–700)
are served locally in WOFF2 format. Latin and Vietnamese subsets cover the
application's Vietnamese/English interface. Each font keeps its upstream SIL
Open Font License alongside the files.

Source: Google Fonts CSS API, retrieved 2026-11-04.
Styles and Unicode ranges: `src/styles/fonts.css`.
Only the two hero display subsets are preloaded; other weights load on demand.
