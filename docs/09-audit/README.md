# Repository Audit — Not Started

Project identity and repository access have not yet been supplied. Do not treat this starter pack as an audit result.

## Audit sequence
1. Repository and toolchain inventory.
2. Application entry points and architecture map.
3. Route and screen inventory.
4. Business capability and actor inventory.
5. API and DTO contract inventory.
6. Authentication/session and authorization audit.
7. Forms, validation and data-state audit.
8. Responsive/accessibility audit.
9. Test, CI/CD, deployment and monitoring audit.
10. Documentation drift and risk assessment.
11. Migration sequencing and pilot selection.

## Required outputs
- `repository-inventory.md`
- `screen-inventory.md` or CSV
- `api-contract-inventory.md`
- `auth-permission-audit.md`
- `risk-register.md`
- `parity-matrix.md`
- `audit-summary.md`

Every finding must include evidence, severity, owner, status and recommended action.
