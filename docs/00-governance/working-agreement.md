# Working Agreement

## Purpose
One shared operating model for developers and Antigravity.

## Roles
- Product owner: confirms business intent, priority and accepted scope.
- Tech lead: owns architecture, API integration decisions and technical approvals.
- Designer: owns visual direction, design tokens and interaction specs.
- Developer: implements scoped tasks and tests.
- QA: validates acceptance criteria, regression and release evidence.
- Antigravity: assists under repository rules; it does not approve its own risky decisions.

One person may hold multiple roles, but approval responsibilities must remain explicit.

## Ready / Done
See `definition-of-ready.md` and `definition-of-done.md`.

## Change control
Architecture, auth/session, API contract, shared design tokens, routing and migration cutover require review by the designated owner.
