# Definition of Ready
A task is ready when:
- [ ] User/business goal and actor are known.
- [ ] Scope and exclusions are explicit.
- [ ] Acceptance criteria are testable.
- [ ] Owning module and affected screens are identified.
- [ ] API/permission evidence exists or the blocker is explicitly assigned.
- [ ] Design/reference is available for visual work.
- [ ] Dependencies and risks are recorded.
- [ ] Test approach is understood.
