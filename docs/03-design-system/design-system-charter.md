# Design System Charter

## Design direction
Full redesign with a clean, light-first enterprise CRM experience. This is a direction, not a final visual specification.

## Principles
- Clear information hierarchy; one dominant primary action per context.
- Generous but disciplined spacing; avoid crowded surfaces and nested cards.
- Neutral surfaces, restrained semantic colors and consistent typography.
- Reusable patterns for page headers, filters, tables, forms, dialogs and feedback.
- Responsive behavior designed deliberately, not merely compressed.
- Accessible contrast, focus, keyboard and labels.

## Required token groups
- color: canvas, surface, surface-muted, text, text-muted, border, primary, success, warning, danger, info.
- typography: family, sizes, weights, line heights.
- spacing: consistent scale.
- radius and elevation.
- breakpoints and content widths.
- motion duration/easing, reduced-motion behavior.

## Rules
Do not finalize hex values until brand/reference audit. Do not let each screen invent its own values. Tokens must be semantic and documented.
