# 08 — Redesign and Accessibility
- Inventory old screen capabilities before redesigning.
- Map every existing action, field, filter, validation, status and permission to the new design.
- Use semantic HTML, labels, keyboard operation, visible focus and appropriate ARIA.
- Dialogs must manage focus and Escape behavior appropriately.
- Tables need accessible headers and understandable empty/loading/error states.
- Visual polish must not obscure hierarchy or primary actions.
