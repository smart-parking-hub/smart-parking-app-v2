# Workflow: API Integration
1. Locate OpenAPI or backend controller/DTO/service.
2. Record endpoint contract and auth requirements.
3. Confirm pagination/filter/sort/error envelope.
4. Add typed API function under owning feature.
5. Add query/mutation and stable query keys.
6. Implement loading/error/empty and invalidation behavior.
7. Test contract mapping and failure cases.
8. Update API inventory and traceability.
