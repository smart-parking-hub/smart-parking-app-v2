# Workflow: Bug Fix
1. Reproduce and capture expected vs actual behavior.
2. Identify affected user, role, route, data and environment.
3. Trace root cause before editing.
4. Check whether bug is frontend, backend, contract, data or environment.
5. Add/adjust regression test.
6. Apply minimal fix; avoid unrelated refactor.
7. Run targeted and broader relevant checks.
8. Report root cause, fix, evidence and residual risk.
