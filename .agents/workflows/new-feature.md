# Workflow: New Feature
1. Confirm request, actors, scope and acceptance criteria.
2. Run business analysis and identify unknowns.
3. Locate owning module and verify API/permission contracts.
4. Perform impact analysis: routes, screens, shared components, data, tests and docs.
5. Produce technical/UI plan; obtain approval for material changes.
6. Implement in a feature branch with small commits.
7. Test happy path, alternate path, validation, permission denial and API failure.
8. Run typecheck, lint, tests and build.
9. Review diff and update docs/traceability.
10. Submit PR with task report and visual evidence.
