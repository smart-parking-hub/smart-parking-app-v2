# Skill: UI/UX Redesign
1. Audit the legacy screen and list every action, field, filter, state and permission.
2. Identify primary user goal and information hierarchy.
3. Apply approved tokens, components, spacing and layout rules.
4. Design desktop/tablet/mobile behavior and keyboard/accessibility behavior.
5. Include loading, empty, filtered-empty, error, success, disabled and denied states as relevant.
6. Map each old capability to new UI; identify intentional changes for approval.
7. Review visual consistency across neighboring screens.
Output: screen spec/wireframe or design link, parity checklist and open decisions.
