# Skill: Design System
1. Inspect existing brand assets and approved visual direction.
2. Define semantic tokens for color, typography, spacing, radius, elevation and breakpoints.
3. Define primitive components and variants with accessibility requirements.
4. Define composition patterns (forms, tables, filters, dialogs, page headers).
5. Document usage and anti-patterns; provide Storybook stories if adopted.
6. Check contrast and light/dark theme requirements before committing tokens.
7. Version breaking token/component changes and audit consumers.
Output: token spec, component inventory, usage examples and adoption plan.
