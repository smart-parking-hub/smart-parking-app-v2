# Skill: Documentation Maintenance
1. Identify the authoritative document for the changed fact.
2. Verify against current source/contract/test.
3. Update status, evidence, owner and last_verified.
4. Keep docs concise and link to deeper sources.
5. Update traceability and module maps where relevant.
6. Mark stale content deprecated or conflicting; preserve history where useful.
Output: list of changed docs and evidence used.
