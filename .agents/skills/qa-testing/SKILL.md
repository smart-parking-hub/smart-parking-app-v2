# Skill: QA and Testing
1. Convert acceptance criteria into positive, negative and boundary tests.
2. Identify actors/permissions and data setup.
3. Test query loading, empty, error, retry and stale data behavior.
4. Test form required/format/server validation and duplicate submission.
5. Test navigation, refresh/deep links and session expiry where relevant.
6. Run relevant unit/component/integration/E2E checks.
7. Record environment, commands, results and reproducible defects.
Output: test matrix, evidence and defect list.
