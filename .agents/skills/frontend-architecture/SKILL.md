# Skill: Frontend Architecture
1. Inspect current architecture and approved ADRs.
2. Identify owning feature and public dependencies.
3. Define route, page composition, data flow, state ownership and error boundaries.
4. Keep server state in TanStack Query by default; global client state only when justified.
5. Define DTO/domain/view-model boundaries only where they prevent real coupling.
6. Check import direction and circular dependencies.
7. Document significant decisions before implementation.
Output: concise technical design, dependency impact and implementation plan.
