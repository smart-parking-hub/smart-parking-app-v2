# Skill: React Implementation
1. Read feature spec, architecture and design-system guidance.
2. Reuse existing components and patterns after checking their contracts.
3. Keep pages focused on composition; isolate feature logic where justified.
4. Use typed props and explicit async states.
5. Keep forms, query state and local UI state in the correct owner.
6. Implement accessibility and responsive behavior alongside the feature.
7. Run tests, typecheck, lint and build; inspect final diff.
Output: implementation, tests, docs and task report.
