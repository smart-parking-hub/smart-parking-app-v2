# Skill: API Integration
1. Find the authoritative OpenAPI/backend controller/DTO/service evidence.
2. Confirm method, path, auth, parameters, request, response, errors and pagination.
3. Map transport DTO to UI model only when necessary; document transformations.
4. Implement through centralized HTTP client and feature API/query modules.
5. Define query keys, cache invalidation, cancellation and optimistic behavior only when safe.
6. Handle field errors and global errors without leaking sensitive payloads.
7. Test success, empty, validation failure, unauthorized and server failure.
Output: contract note, API implementation and tests.
