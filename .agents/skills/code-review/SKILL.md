# Skill: Code Review
Review in this order:
1. Business correctness and parity.
2. Security, authorization and privacy.
3. API contract correctness.
4. Architecture boundaries and dependency direction.
5. State/cache correctness and async race conditions.
6. Accessibility and responsive UX.
7. Test quality and coverage of changed behavior.
8. Maintainability, duplication and performance.
Report findings with severity (Blocker/Critical/Major/Minor), file/line, impact and actionable fix. Do not approve based on style preference alone.
